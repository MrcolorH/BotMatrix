# 🍎 TGBot for macOS (原生桌面控制中心 v1.2.0)

> 基于 **Swift 6 & SwiftUI** 纯原生构建的高性能 Telegram 机器人控制台。  
> 具备 **全网视频自主识别解析**、**图文双重毛玻璃与可逆折叠防社死保护**、**Mac mini 本地反重力 (AGY) CLI 远程调用** 与 **管理员白名单严格权限隔离**。

---

## 🌟 核心特性一览

### 1. 🎬 全网多平台视频流自主识别（公共服务）
- **单链接无感识别**：用户发送任意一条链接，Bot 自动根据正则识别平台并调用对应引擎：
  - 🐦 **Twitter / X**（FixTweet / TwitterDown / VxTwitter 多线路兜底）
  - 🎵 **TikTok / 抖音**（无水印 MP4 直链提取）
  - 📺 **Bilibili**（BV / b23.tv 短链解析）
  - ▶️ **YouTube**（视频 / Shorts 直链信息）
- **零带宽中转**：提取到的直链直接返回给 Telegram 用户，由客户端/浏览器直连下载，Mac 本机零存储、零中转负担。

### 2. 🛡️ 终极防社死：图文双重毛玻璃 + 可逆折叠
- **双重剧透毛玻璃**：
  - 封面图：带 Telegram 原生毛玻璃遮罩（`has_spoiler: true`）；
  - 推文摘要与作者：使用 Telegram 剧透遮罩（`<tg-spoiler>`），默认不露一个敏感字！
- **随时可逆交互折叠**：
  - 每条卡片配备 `[ 🔒 立即折叠隐藏 ]` 按钮，点击后原地将敏感内容全部抹除并折叠；
  - 随时点击 `[ 👁️ 展开完整信息 ]` 原地恢复，无缝切换！
- **超时自动防误窥**：
  - 展开状态下默认 **5 分钟** 无操作，Bot 后台自动调用 API 抹除文案并折叠，即使忘记关闭也不会留下任何痕迹。

### 3. 🤖 Mac mini 本地反重力 (AGY) CLI 远程调度（管理员私有）
- **远程派发指令**：
  - 发送 `/ai <任务/问题>` 或 `/agy <任务>`，Telegram Bot 会在 Mac 本地后台调用 `/Users/colorh/.local/bin/agy -p "<prompt>"`，执行完毕后将结果格式化回传至 Telegram。
- **Mac mini 宿主监控**：
  - 发送 `/status`，Bot 秒级生成并回传这台 Mac mini 的设备名、操作系统版本、开机运行时间（Uptime）、CPU 核数、内存占用、磁盘剩余空间与反重力状态。

### 4. ☀️ 每日晨报定向推送中心（专属定制服务）
- **自主申请加入推送名单**：
  - 用户发送 `/getNews`，即可将自己的账号加入每日晨报推送名单；
  - 成功加入后，机器人立即回传详细的**晨报标签定制使用说明**。
- **用户自由定制关注标签**：
  - 用户可按需订阅关注领域：`/addTag AI发展`、`/addTag 机器人发展, 大肥鱼现状`；
  - 随时管理与查看个人标签：`/myTags`、`/removeTag <标签>`；
  - 即时试读预览：`/previewNews`，让后台 CLI 立即生成今日专属试读样刊。
- **后台 CLI 每天 08:00 定时智能采集与拼接**：
  - 每天早晨 08:00，调度器自动触发，调度后台反重力 CLI 针对每个订阅用户的定制标签抓取 AI/机器人大事与现状观察，格式化拼接后精准推送至对应用户；
  - 具备今日防重复推送机制与离线重试。
- **自由随时退出推送名单**：
  - 发送 `/stopNews` 即可随时退出晨报推送名单，零骚扰。

### 5. 🔥 零重启插件中心与热更新市场 (Plugin Hub)
- **零停机动态热加载 (Hot Reload)**：
  - 机器人长轮询连接 (`getUpdates`) 与功能插件彻底解耦；
  - 在 `~/.tgbot/plugins/` 目录下添加或更新 Python / Shell / Prompt 插件时，**无需重启 App，长轮询不断线**，点击「⚡️ 立即热重载」毫秒级即时生效！
- **一体化插件中心 (Plugin Hub)**：
  - 桌面端将核心服务、动态热更插件与扩展市场**完全合并统一**；
  - 顶部直接提供「📂 打开插件目录」与「⚡️ 立即热重载」快捷按钮；
  - 支持在「🧩 内置核心服务」、「🔥 动态热更插件」与「🛍️ 插件市场推荐」三栏间顺畅切换，汇集官方精选模板（🪙 加密货币与金价行情、📰 HackerNews 极客头条、⚡️ Mac mini 运维命令箱等），支持一键安装、更新代码与即时生效。

### 6. 🔐 管理员白名单权限隔离
- 采用 Telegram 用户的唯一纯数字 `User ID` 进行鉴权；
- 在 Mac App 设置页的「管理员 ID 白名单」中填入您的 ID；
- 视频流直链提取面向所有人开放；任何高权限指令（`/ai`, `/agy`, `/status`）均对非白名单用户进行拦截，确保公司电脑绝对安全。

### 7. 🐧 本地 QQ 小号接入与 NapCat App 内一键极速配置
- **OneBot v11 原生 WebSocket 直连**：通过本地 `ws://127.0.0.1:3001` 协议端连通 QQ，将反重力 CLI 与视频流解析无缝接入 QQ 私聊与群聊；
- **真·App 内一键安装向导**：首次使用无需跳出到外部网页或手动解压，在 TGBot 界面内直接点击「一键配置 NapCat」，内置多节点镜像秒级完成下载、组件解压、初始化与 QQ 入口安全接管；
- **智能双开无感共存**：生成的加载器支持 `--no-sandbox` 守护进程与官方日常 QQ 同时运行，互不干扰；
- **随时安全恢复**：设置页自带「恢复原版 QQ 入口」一键撤销功能，安全无忧。

```text

├── Package.swift               # Swift Package Manager 工程配置文件

├── Sources/
│   ├── App.swift               # App 入口、窗口尺寸与菜单栏托盘
│   ├── Core/
│   │   ├── BotController.swift # 机器人长轮询与运行监控
│   │   ├── Models/             # Telegram 数据模型、日志与解析结果
│   │   └── Services/           # Telegram 客户端、存储、日志与 AgyService (反重力)
│   ├── Modules/
│   │   ├── BaseModule.swift    # 插件模块接口协议
│   │   ├── ServiceRegistry.swift # 服务注册与分发中心
│   │   ├── Video/              # 多平台自主识别、双重毛玻璃遮罩与可逆折叠卡片
│   │   ├── Twitter/            # Twitter 专属解析多引擎
│   │   └── AI/                 # 反重力 (AGY) CLI 远程调度与 /status 模块
│   └── UI/
│       ├── MainView.swift      # 主窗口导航视图
│       ├── Components/         # 状态徽章、指标卡片等复用组件
│       └── Views/              # 控制台、插件管理、日志与设置页
└── build/
    └── TGBot.app               # 生成的双击即开 Mac 独立应用程序包
```

## 🚀 编译与运行

### 方式一：直接运行已编译应用
```bash
open macos_version/build/TGBot.app
```
或者直接在访达中将 `TGBot.app` 拖拽到「访达 -> 应用程序 (Applications)」即可像普通 Mac 软件一样使用。

### 方式二：一键全自动编译打包
```bash
cd macos_version
./build_app.sh
```
